# ReArc Brand Guidelines & Design System

The definitive visual design system for **ReArc** — a clean-room, open-source reimplementation of the Arc browser paradigm on macOS (Swift/AppKit/SwiftUI shell + Chromium engine).

---

## 1. Brand Identity & Mark

### 1.1 The "Sunrise" Mark
The ReArc mark is a sun rising behind a thick curved horizon:
- **The Arc**: a heavy, round-capped horizon band (navy at the left end, blue across the rest, with a darker overlap where the two pieces meet). It is opaque and sits **in front of** the sun.
- **The Sun ("Re")**: a vermillion disc that rises again from behind the arc. Only the part above the arc is drawn; nothing shows beneath it.
- **Character**: chunky, soft-cornered, flat colour with one overlap tint, in the same family of weight and softness as the app's reference icons. Palette and construction are ReArc's own (see 3.3).

Generated by `brand/explore/gen/export_marks.py` (edit the constants there, not the SVGs).

## 2. Clear Space & Minimum Sizing

### 2.1 Clear Space
To preserve visual authority and avoid visual contamination:
- The minimum clear space surrounding the mark is **$X = 0.25 \times \text{Width}$** of the mark.
- For `logo.svg` ($512\,\text{px}$), the exclusion boundary is at least $128\,\text{px}$.
- No typography, borders, ui chrome, or graphics may enter this perimeter.

```
       +-------------------------------+
       |             0.25X             |
       |       +---------------+       |
       | 0.25X |  ReArc Mark   | 0.25X |
       |       +---------------+       |
       |             0.25X             |
       +-------------------------------+
```

### 2.2 Minimum Size Matrix

| Scale | Target Context | Recommended Asset | Rendering Notes |
|---|---|---|---|
| **16 \u00d7 16 px** | Browser Favicon, Native Tab Strip Icon | `logo.svg` | Verified: sun and arc stay separate at 16 px (full colour). Use `logo-mono.svg` only if single-colour is required; its gap is 1 px at this size. |
| **24 \u00d7 24 px** | Sidebar Toolbar, Window Header Controls | `logo.svg` | Clean icon badge. |

### 4.1 Space Theming Compatibility
ReArc supports the 27 measured space swatch swatches (`space.pastel.1..9`, `space.greyscale.1..9`, `space.drab.1..9`) documented in `docs/DESIGN-TOKENS.md`:
- When a user selects a space swatch, ReArc derives the sidebar gradient and tab tint procedurally.
- The ReArc primary brand accents (`rearc.cobalt` and `rearc.cyan`) remain active on window-level controls (plus-button, command bar trigger, profile switcher) to anchor the application identity across themed spaces.

## 5. Typography

### 5.1 Wordmark Typography
- The wordmark "ReArc" uses macOS native system typography:
  - Font Stack: `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", sans-serif`
  - Weight: Bold (`700`)
  - Tracking / Letter Spacing: `-2px` (at 88pt) for optical tightness
  - Color treatment: "Re" in `rearc.text.primary` (`#0F172A` / `#F8FAFC`), "Arc" in the mark blue (`#2740FF` / `#7C8FFF`).

### 5.2 Shell UI Font Tokens
In accordance with `docs/DESIGN-TOKENS.md` \u00a73, the shell UI uses Apple SF Pro:
- `FontSizeBody`: 13 pt Medium (tab row titles)
- `FontSizeSubtitle`: 11 pt Regular (URL / subtitle hints)
- `FontSizeH1`: 15 pt Semibold (Space header title)
- `FontSizeSectionHeader`: 11 pt Semibold tracked +0.5 (Pinned / Today headers)

## 6. Brand Do's & Don'ts

### DO:
- **DO** use `brand/logo.svg` against clean light or dark backgrounds.
- **DO** use `brand/logo-mono.svg` with `currentColor` for menu bars, toolbars, and monochrome surfaces.
- **DO** maintain the standard 0.25X clear space boundary around the mark.
- **DO** scale the mark uniformly (constrain aspect ratio 1:1).
- **DO** use the macOS squircle composition (`brand/app-icon.svg`) for all desktop app packaging.

### DON'T:
- **DON'T** apply rainbow gradients or multi-hue blends to the mark.
- **DON'T** render the mark with faux-3D shading, glossy bubbles or heavy drop shadows.
- **DON'T** show any part of the sun below the arc, or put the sun in front of the arc.
- **DON'T** skew, rotate or flip the mark.
- **DON'T** change the arc's thickness relative to the sun, or the navy/blue overlap.
- **DON'T** place the full-colour mark on low-contrast backgrounds (e.g., bright blue or vermillion backgrounds).
- **DON'T** use the mono mark where a hat-like silhouette would confuse: at small sizes the sun and arc can read as a brimmed hat.
